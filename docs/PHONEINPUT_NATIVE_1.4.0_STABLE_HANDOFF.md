The Native Android + Windows implementation from the supplied
`PhoneInputEnhanced_1.4.0-native-preview.10` source package is integrated under
the `native/` directory as the 1.4.0 stable line.

- `native/PhoneInputEnhanced_1.4.0-native-preview.10_CURRENT_VERSION_SUMMARY_2026-08-09.md`

directories for rollback.
