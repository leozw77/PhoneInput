PhoneInputEnhanced 1.4.0

本版新增 Windows 图片中转栏：
- 手机截图/图片通过系统“分享”发送到 PhoneInputEnhanced 后，Windows 自动在任务栏上方显示最近图片缩略图。
- 最多保留最近 5 张缩略图。
- 按住缩略图可像资源管理器文件一样拖入 ChatGPT、Chrome 等支持文件拖放的应用/网页。
- 单击缩略图使用 Windows 默认图片查看器打开。
- 右上角 × 仅隐藏中转栏；下次收到图片会自动重新显示。
- 图片文件仍保存在 Downloads\PhoneInputEnhanced\Images。
