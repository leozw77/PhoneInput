# Native preview.2 实机验收清单

- [ ] 触控板快速轻触：只产生一次左键点击。
- [ ] Chrome 标签快速点击：标签被选中，不被拖起。
- [ ] 两次快速轻触：Windows 双击行为正常。
- [ ] 单指直接滑动：移动鼠标，不产生左键按下。
- [ ] 单指稳定按住约 0.22 秒后明显移动：进入左键拖动；松手立即释放。
- [ ] 微信图片详情：按住后移动可拖图。
- [ ] 双击第二次按住约 0.15 秒后移动：可进入双击拖动；松手释放。
- [ ] “拖动锁定”开启：按钮显示 ✓，连续多次滑动仍保持左键。
- [ ] “拖动锁定”关闭：立即释放左键。
- [ ] 拖动锁定时加入第二根手指：锁定被强制释放，不出现卡住左键。
- [ ] 拖动过程中切后台：Windows 不残留 LeftButtonDown。
- [ ] Wi-Fi 断开/自动重连后：拖动锁定状态不会错误保留。
- [ ] 左/中/右实体按钮、截图、复制、粘贴、三窗口切换没有回归。
